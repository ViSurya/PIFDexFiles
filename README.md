# **PIFDexFiles**

This repository contains all sprites and custom sprites used in the **[Pokémon Infinite Fusion](https://www.pokecommunity.com/showthread.php?t=347883)** game. These assets are used in the **[Infinite Fusion Calculator](https://www.pokefusion.japeal.com/)** to showcase Pokémon combinations and their unique designs.

---

## **About the Repository**
- 🖼️ **Sprites Collection**: A comprehensive collection of both original and custom sprites used in Pokémon Infinite Fusion.
- ⚙️ **Integration Ready**: These sprites are optimized for use with the Infinite Fusion Calculator.
- 🎨 **Community Contributions**: Includes custom sprites created by the community to expand the fusion possibilities.

---

## **Features**
- Thousands of Pokémon fusion sprites.
- Includes both **default sprites** and **custom sprites** made by fans.
- Optimized and categorized for easy access.

---

## **How to Use**
1. Clone the repository to access the sprite files:
   ```bash
   git clone https://github.com/ViSurya/PIFDexFiles.git
   ```
2. Navigate through the folders to find specific sprites:
   - **`/sprites/`**: Contains the main sprites.
   - **`/custom_sprites/`**: Contains community-made custom sprites.

3. Use these sprites in the **Infinite Fusion Calculator** or for other fan-made projects.
